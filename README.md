# Sistema de Respaldo y Restauración en xv6

Este repositorio contiene el código fuente y la documentación del proyecto final para el curso de Sistemas Operativos (IS-380).

## 📂 Estructura del Proyecto
*   **`documentacion/`**: Contiene el informe técnico en Markdown, las imágenes de las pruebas y la presentación.
*   **`user/`**: Contiene el código fuente en C de los comandos `backup.c`, `restore.c` y la suite de pruebas `test_backup.c`.
*   **`kernel/` y `mkfs/`**: Código base del sistema operativo xv6 (MIT).
